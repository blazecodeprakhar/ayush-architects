# ayush-architects

Modern, luxury architectural portfolio and design studio website for **Ayush Architects** — *Spaces For Better Tomorrow*.

## Features

- **Luxury Architectural Aesthetic**: Built with React, TypeScript, Vite, Tailwind CSS, and shadcn/ui.
- **Dynamic Dark & Light Mode**: Realistic light-switch toggle with custom `#171411` deep espresso dark mode foundation.
- **Architectural Services & Process**: Complete showcase of 12 architecture & design services and 10-step execution process.
- **Interactive Portfolio & Swipe Gallery**: Curated spaces with interactive touch/mouse swipe gallery and filterable showcases.
- **Direct Consultation Booking**: Contact and consultation inquiry form integrated with responsive toast notifications.

## Tech Stack

- **Framework**: React 18 + Vite
- **Language**: TypeScript
- **Styling**: Tailwind CSS + shadcn/ui
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Theme**: next-themes

## Getting Started

### Prerequisites

- Node.js (v18+)
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/blazecodeprakhar/ayush-architects.git

# Navigate into the project directory
cd ayush-architects

# Install dependencies
npm install

# Start development server
npm run dev
```

### Build for Production

```bash
npm run build
```
